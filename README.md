# wallet-connect-buttons

Wallet Connect buttons for NP Wallet, Business Wallet and 18up, for React, Vue and plain HTML/JavaScript, plus
example apps and backends. This repository replaces five separate repositories; their full histories were imported
under `packages/` and `examples/` (tags are prefixed `react-`, `vue-`, `vanilla-`).

| Package | Folder |
|---|---|
| `wallet-connect-button-react` | `packages/wallet-connect-button-react` |
| `wallet-connect-button-vue` | `packages/wallet-connect-button-vue` |
| `wallet-connect-button-vanillajs` | `packages/wallet-connect-button-vanillajs` |
| React example app | `examples/react` |
| Vue example app | `examples/vue` |
| Static example pages | `examples/static` |
